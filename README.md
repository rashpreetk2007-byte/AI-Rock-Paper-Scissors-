# ✊ AI Rock Paper Scissors

A mobile-friendly Rock Paper Scissors game built with Python and Streamlit.

## 📌 Project Overview

AI Rock Paper Scissors is an educational computer-vision project designed to demonstrate a camera-based Rock Paper Scissors game interface on a mobile device.

The application allows the user to capture a hand image using the device camera, select the corresponding gesture, and play against a computer-generated move.

## ✨ Features

- 📷 Camera-based image capture
- ✊ Rock
- ✋ Paper
- ✌️ Scissors
- 🤖 Computer opponent
- 🏆 Automatic winner calculation
- 📊 Player score
- 🤝 Draw counter
- 📜 Game history
- 🔄 Reset game
- 📱 Mobile-friendly Streamlit interface

## 🛠️ Technologies Used

- Python
- Streamlit
- NumPy
- Pillow
- Requests
